# BistRadar data feed

Public JSON feed for the [Arz Radar](https://github.com/onurkuru/bistradar) iOS app —
BIST dividend calendar + IPO tracker. Source code and scraper live in the private
`bistradar` repo; this repo holds only the generated `feed.json`, synced automatically
by that repo's GitHub Action.

Data is sourced from KAP (Kamuyu Aydınlatma Platformu) and İş Yatırım — both public,
official disclosure sources.
